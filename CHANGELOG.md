# Changelog

All notable changes to KryomCode are documented in this file.

This project follows a versioned release approach. Release entries describe
verified changes. Planned or incomplete functionality must not be presented
as completed.

## Changelog Guidelines

- Add new work under [Unreleased].
- Group changes under Added, Changed, Fixed, Security, or Removed.
- Move verified changes into a versioned release section when a release
  is actually published.
- Use the actual release date; never invent a release date.
- Keep entries concise, specific, and verifiable.
